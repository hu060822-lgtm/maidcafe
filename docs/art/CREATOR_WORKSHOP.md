# 創作者工作坊

創作者工作坊是一個不用寫程式、不用記檔名的視窗工具，用來：

- **匯入**你自己畫的或 AI 生成的立繪（拖進視窗即可，會自動縮放、對齊、命名、登記）。
- **創造**立繪：用「立繪產生器」選髮型、髮色、眼型、服裝，一鍵畫出一位角色的全部姿勢與表情。
- **管理**：看每位角色還缺哪些圖、把草稿標為完成、填寫角色設定、確認並鎖定外觀、新增角色。

相關文件：[美術系統架構](ART_SYSTEM.md)・[新增角色教學](ADD_CHARACTER.md)・[AI 生成流程](AI_WORKFLOW.md)

---

## 1. 開啟

| 方式 | 作法 |
| --- | --- |
| macOS / Linux | `tools/art/workshop.sh` |
| Windows | 點兩下 `tools\art\workshop.cmd` |
| Godot 編輯器 | 開啟 `res://scripts/art/workshop/creator_workshop.tscn`，按 F6 |

若 `godot` 不在 PATH，先設定 `GODOT` 環境變數指向 Godot 4.3 執行檔。

## 2. 畫面

```
┌ 角色清單 ┬──────── 素材｜產生器｜角色設定 ────────┬ 遊戲中的樣子 ┐
│ S 小春 27/27 │  每一格 = 遊戲需要的一張圖           │  即時預覽     │
│ S 凜   27/27 │                                    │  姿勢/服裝/表情│
│ …            │                                    │              │
```

- 左邊：全部角色。數字是「已有圖片／需要的圖片」。
- 中間：三個分頁（下面說明）。
- 右邊：這位角色**在遊戲裡實際顯示的樣子**，可切換姿勢、服裝、表情。沒有圖的組合會顯示灰色剪影與 `[MISSING ART]`。
- 右上角「字－／字＋」可調整工作坊的字體大小。

## 3. 「素材」分頁：匯入自己的圖

每一格是一張遊戲需要的圖，標示狀態：**缺少**、**草稿**、**完成**。

**匯入一張圖**

1. 點選要放的格子（例如「站姿・女僕制服／本體」）。
2. 把圖片檔拖進視窗，或按「匯入圖片…」。
3. 圖片是白底或單色底時，先勾「去除純色背景」。

工作坊會自動：轉成 PNG、等比例縮放到規定尺寸（立繪 1024×1536，貼齊畫布底部置中）、用正確的檔名存到正確的資料夾、在 manifest 登記為「草稿」。

**一次匯入很多張**：如果檔名已經符合命名規範（例如 `chr_koharu_face_stand_smile.png`），直接把一批檔案拖進來，會各自放進對應的格子，不用先點選。

**其他按鈕**

- 「標為完成」：你檢查過、認可這張圖之後按。只有你能把圖標為完成，工具不會自動標。
- 「退回草稿」、「刪除圖片」。
- 「複製 AI 提示詞」：把這一格的 AI 生成提示詞複製到剪貼簿，貼到你用的 AI 繪圖工具。

**會被拒絕的圖**：沒有透明背景的立繪（請勾去背）、全透明的圖。這是為了避免壞圖進到遊戲。

## 4. 「產生器」分頁：自己創造立繪

不需要任何繪圖軟體。左邊調整，中間即時預覽：

| 項目 | 選項 |
| --- | --- |
| 後髮 | 長髮、鮑伯頭、短髮、馬尾、雙馬尾、丸子頭、側辮 |
| 瀏海 | 齊瀏海、中分、斜瀏海、空氣瀏海 |
| 眼型 | 圓眼、下垂眼、上挑眼、半睜眼 |
| 顏色 | 髮色、瞳色、膚色（任意顏色） |
| 其他 | 呆毛、鬢髮、身高 |
| 配件 | 女僕頭飾、蝴蝶結、髮夾、花飾、眼鏡 |
| 服裝（每套各自設定） | 經典／荷葉邊／素雅女僕裝、針織外套、帽 T、襯衫與高腰裙、水手服、運動外套；主色、副色、緞帶色 |

- 「儲存設定」：把目前的設定存成 `godot/art/characters/<角色ID>/maker.json`。
- 「畫出全部立繪」：依設定畫出這位角色的所有姿勢、服裝與表情（S 級 27 張），存成「草稿」。之後到「素材」分頁檢查，滿意再標為完成。

產生器畫的是乾淨的向量風 Q 版動畫立繪，適合快速定案造型與讓遊戲先有圖可用。想要更精緻的插畫，可以把產生器的圖當作造型參考，用 AI 或手繪畫出正式版，再從「素材」分頁匯入覆蓋同一格。

也可以用指令一次重畫：

```bash
tools/art/workshop.sh draw            # 所有有 maker.json 的角色
tools/art/workshop.sh draw koharu rin # 指定角色
```

## 5. 「角色設定」分頁：Character Bible

填寫外貌、髮型、髮色、瞳色、身形、服裝、配件、代表色、表情特徵。

- 「TBD／尚未決定」代表還沒決定。
- 全部填完後按「確認並鎖定外觀」。鎖定後 AI 提示詞才會以正式模式產生，之後任何未經解鎖的修改都會被檢查工具擋下。
- 要修改已鎖定的外觀，先按「解除鎖定」。

## 6. 新增角色

按右上角「＋新增角色」，輸入 ID（小寫英文、數字、底線）、名字、分級（S／A／B）。工作坊會建立空白設定並登記這個分級需要的全部圖片格子。接著就能用產生器或匯入的方式補圖。

遊戲端要讓角色登場，仍需在遊戲資料中加入同一個 ID（見 [新增角色教學](ADD_CHARACTER.md)）。

## 7. 檢查

「檢查素材」會跑和 `tools/art/art.sh validate` 相同的檢查：檔案是否存在、格式與尺寸、缺少的差分、重複或放錯位置的圖、沒登記的檔案。

## 8. 目前九位女僕的圖是「提案」

小春、凜、雫、雪乃、楓、紬、千夏、葵、日和目前各有 27 張由產生器畫出的**草稿**。造型是依照原型的髮色與個性做出的**提案**，不是定案：

- `maker.json` 中標記 `"status": "proposal"`，manifest 中狀態是「草稿」。
- Character Bible 的外觀仍是未確認，沒有被鎖定。
- 你可以在產生器分頁直接改成你想要的樣子再重畫，或匯入自己的圖取代。
