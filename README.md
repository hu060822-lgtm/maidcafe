# MAIDEN PARADE（暫定名稱）

3D 生活模擬 × 女僕咖啡廳經營 × 角色養成 × 街區探索。
這是企劃書第 8 節「第一版可玩規格（MVP）」的可玩原型，用來驗證核心循環。

## 執行

需要 Node.js 20 以上。

```bash
npm install
npm run dev      # 開啟 http://localhost:5173
npm test         # 無畫面的模擬測試（營業、記憶、尋路）
npm run build    # 產生 dist/，可直接放到任何靜態網站
```

## 技術選擇

- **Three.js + TypeScript + Vite**：瀏覽器即開即玩、改完立即重新整理，適合快速驗證玩法。PC 瀏覽器優先。
- 遊戲邏輯（`src/game/`）完全不依賴畫面，可以在 Node 裡直接跑一整天的營業做測試；之後若要換到 Godot / Unity，規則與資料可以照搬。
- 美術全部是程式產生的簡單幾何造型（佔位用），所有角色、店家、劇情皆為原創。

## 一天的流程

| 階段 | 內容 |
|---|---|
| ☀ 白天・街區探索 | 6 個地點，每天 4 次行動：採購食材、認識新客人、發傳單、和女僕聊天、與甜點店簽約 |
| 🌤 下午・營業準備 | 菜單、班表（接待／廚房／外場／舞台／休假）、活動、裝潢擺設。不限時 |
| 🌙 晚上・正式營業 | 即時模擬。女僕依崗位自主工作，玩家可介入 |
| 🌌 深夜・結算 | 收支、評價、員工狀態、角色事件、設備升級、安排明天休假 |

## MVP 驗收對照

| 驗收條件 | 實作 |
|---|---|
| 開始新遊戲 | 標題畫面；自動存檔於 localStorage |
| 街區探索 | 6 個地點各有用途（`src/game/world.ts`） |
| 採購材料 | 三間店販售 16 種食材；糖霜屋可簽供應合約 |
| 安排女僕工作 | 下午「排班」分頁；營業中也能改崗位 |
| 開始營業 | 17:00–22:00 即時模擬（約 4 分鐘，可 1x/2x/3x、暫停） |
| 觀察女僕自主工作 | 女僕依崗位優先順序挑選工作、A* 尋路、頭上顯示目前動作與進度；空閒時會聊天、自言自語 |
| 親自介入營業 | 店長可親自帶位／點餐／送餐／下廚／清理／處理客訴／寒暄；對女僕下指令消耗「指揮點數」（每 40 秒回 1 點，上限 5） |
| 處理突發狀況 | 客訴（客人等太久會發脾氣，需店長或管理 ≥50 的女僕處理）、打翻餐點（地板髒污＋重做） |
| 每日財務結算 | 收入、食材、薪資、維護、水電、活動、宣傳、家具；滿意度、員工幸福度、人氣、熟客比例 |
| 前一天的經歷影響隔天 | 見下方「記憶系統」 |

## 記憶系統（今天的選擇如何影響明天）

**顧客**（`CustomerMemory`）會記住：來店次數、忠誠度、對每位女僕的好感、指名女僕、老位子、喜歡的料理、上次的滿意度與原因。

- 上次等太久 → 這次耐心較低，進門時會說「上次等好久……」。
- 對某位女僕好感累積 → 指名她，工作分配會優先讓她服務；她休假時客人會失望。
- 上次很滿意 → 更常來店、坐老位子、點上次喜歡的料理。
- 第 4 次來店且忠誠度夠高 → 成為熟客；第 6 次以上 → 可能帶朋友來。
- 客訴被無視或等到離開 → 之後來店機率下降，隔天早上會聽到他在商店街抱怨。

**女僕**會記住：昨天是否過勞、被稱讚、出錯、休假，隔天的晨報、營業開始時的台詞與心情都會不同。疲勞會跨日累積；心情連續三晚過低會辭職。

## 內容數量

| 項目 | 數量 |
|---|---:|
| 女僕 | 3（小春、凜、雫；不同個性與成長方向） |
| 顧客 NPC | 12（一般 6、可培養熟客 4、特殊 2） |
| 料理 | 15（飲品／甜點／主餐各 5）＋ 1 道可解鎖的招牌料理 |
| 可探索地點 | 6 |
| 活動 | 3（主題服裝日、限定菜單日、小型舞台表演日） |
| 特殊顧客事件 | 2 條（千鶴奶奶的布丁秘方、雨宮先生的小說） |
| 女僕個人事件 | 每人至少 1 條，另有員工間關係事件 |

## 程式結構

```
src/game/          純邏輯（可在 Node 測試）
  types.ts         資料型別
  data/            女僕、顧客、料理、家具、地點、活動
  layout.ts        咖啡廳格子、家具擺設與走道檢查
  path.ts          A* 尋路
  business.ts      營業即時模擬：顧客 AI、女僕工作分配、突發狀況、玩家指令
  settlement.ts    結算、記憶更新、角色事件、換日
  world.ts         街區探索、商店、店鋪風格
src/render/        Three.js 3D 場景、角色模型、鏡頭、點選
src/ui/            介面與操作
tests/             模擬測試
```

## 操作

- 左鍵拖曳旋轉、右鍵拖曳平移、滾輪縮放；選取角色後按 `F` 跟隨並拉近觀察
- 營業中：`空白鍵` 暫停、`1` `2` `3` 調整速度、`Esc` 取消選取
- 點擊客人、女僕、地上的髒污、待整理的桌子、出餐台的料理即可介入；點地板讓店長移動
