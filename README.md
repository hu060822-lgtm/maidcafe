# MAIDEN PARADE — A Living Cafe

3D 女僕咖啡廳經營 × 生活模擬。所有角色、店家、劇情皆為原創，美術是程式產生的簡單幾何造型（佔位用）。

- `godot/`：**正式版本（Godot 4.3，GDScript）**。包含 MVP 的完整循環與「A LIVING CAFE」拓展。
- `web-prototype/`：第一版 Three.js/TypeScript 原型（PR #1），只作為參考保留。

## 執行（Godot 4.3）

1. 下載 [Godot 4.3 stable](https://godotengine.org/download/archive/4.3-stable/)（標準版即可，不需要 .NET）。
2. 在 Godot 專案管理器選「匯入」，選 `godot/project.godot`，按「執行」。
   或命令列：`godot --path godot`

使用 GL Compatibility 渲染器，一般內顯也能跑。中文字型使用系統字型（Windows：微軟正黑體；macOS：蘋方；Linux：Noto Sans CJK / 文泉驛）。

## 一天的流程

| 階段 | 內容 |
|---|---|
| ☀ 白天・商店街 | 4 個時段、6 個地點。街坊依照每週作息出現在不同地方；多聊幾次會提出合作。可以在店裡找女僕聊天、發現她們的心事 |
| 🧹 開店準備 | 菜單（含季節、招牌、聯名料理）、採購、排班、家具擺放（即時顯示動線）、活動、音樂、燈光、特別日準備 |
| 🍰 營業 | 即時模擬。女僕依崗位、習慣、關係自己挑工作、交接、補位；玩家用指揮點數下指令、親自處理工作 |
| 🌙 打烊後 | 營業報告、評價（含客人來店原因）、動線與擁擠熱點、夜間劇情；店裡只剩女僕們，她們會做營業時看不到的事 |

## 「會生活的咖啡廳」做了什麼

**女僕**
- 習慣（整理控、閱讀時光、熱心補位、留到最後、聊天王、熟客的朋友、看窗外）由實際行為累積、不練就慢慢淡掉，並反過來改變她空檔時的選擇。
- 關係有四個面向：親近、信任、默契、摩擦。交接越多默契越高、被幫忙信任上升、工作量長期不平均會產生摩擦；每一次變化都記錄原因，重要的共同經歷會留在筆記本。
- 心事（同事摩擦、對自己沒信心、硬撐的疲勞、想換工作、擔心沒來的熟客、想家）從真實狀況產生，先以行為出現在店裡，白天找她聊才知道原因；玩家可以介入、換個方式處理或先觀察，每條路都有後續。
- 空檔行為：聊天、看書、擦桌子、看窗外、和熟客聊兩句、休息、打烊後留下來練習。

**客人**
- 朋友、夫妻、同事、家人、同好等關係，會約好一起來、先到的人會等朋友；常在店裡碰面又合得來的熟客會自己變熟。
- 習慣會被學起來並影響來店：星期幾來、坐哪裡、點什麼、指名誰；被記住的客人會說「老樣子」，老位子被坐走會失望。
- 特殊行為：看書久坐、拍照上傳（帶來話題）、問喜歡的女僕有沒有上班、等朋友、對新菜單好奇、安靜觀察。
- 口碑：料理話題度、口碑分數、介紹新客人、知名女僕。

**店與街**
- 工作交接、優先順序、補位，不會重複搶同一件事，卡住 30 秒會交還；走不過去會繞路，不會疊在同一格。
- 管理指令：外場優先、熟客優先、指定工作優先、暫停接客、改崗位、休息、暫停某人、指派工作、店長親自處理或去寒暄。
- 突發狀況：送錯餐、打翻、設備故障、換座位、客人糾紛、過勞、冷氣壞掉、雨天、擁擠。
- 家具改變行為：沙發座、書架、花瓶（要有人照顧）、舞台、展示櫃、隔間屏風等。
- 商店街居民 5 位（各有每週作息）、3 種合作、季節食材、祭典、特賣、新店開幕、天氣。
- 每日瞬間與回憶相簿：特別的瞬間會自動截圖存進相簿；生日、週年可以事先準備。

## LIVING HEARTS：每個人都有自己的生活

- **女僕的個人生活**：每位女僕有喜歡／不喜歡的事物（音樂、燈光、天氣、活動、家具、料理、忙碌或安靜），當天真的發生了才會影響心情，原因寫在筆記本。休假日會去她喜歡的地方，白天逛商店街可能遇到她；兩個要好的人同一天休假會一起出門。
- **主動找店長**：累了、被誇獎、想要某樣東西時，她會在打烊後或早上走到店長身邊（「店長，有空嗎？」）。點她就能聽她說。答應的事會變成**約定**，晚上自動檢查有沒有做到，不需要回報：做到了信賴上升、她會記得並在聊天時提起；沒做到、或兩天都沒理她，她也會記得。
- **對店長的信賴**：影響她的心情基準、個人故事能不能展開、撐不撐得下去。
- **個人故事**：9 位女僕各有兩段故事（小春的歌詞本、凜的料理比賽、雫寄回家的照片、雪乃的小說……），只有條件真的達成才會發生；選擇會留下約定或回憶。
- **單向關係**：每個人對每個人的看法分開記錄（A → B）。被幫忙的人更信任幫忙的人；工作量不平均時只有累的那一方會不滿。摩擦太高的兩人打烊後會吵架，結果取決於對方有多信任她；沒說開的架，之後其中一人幫了另一人時會和好。還有小老師、互相較勁、一起休假等雙人事件。
- **客人的生活**：健太找工作→錄取後改成星期五下班來；早瀨先生趕截止日幾天不來；美咲準備攝影比賽；小陸生日由爺爺帶來吃布丁。客人對店有「印象」（料理、服務、自在、被記住），會慢慢淡掉，也會影響來店；秋子阿姨會把店的事說給朋友聽；認識的客人會記得一起度過的晚上，下次碰面會提起。
- **家具與季節**：抱絨毛熊、替盆栽澆水、放黑膠唱片、整理展示櫃、在舞台上偷偷練習、在沙發座打盹、在拍照區合照（全部走到家具旁的可走格子，與尋路、碰撞、工作站相容）。季節裝飾會改變風格、吸引喜歡新奇的客人，季節結束自動收起。
- **回憶相簿**：每則回憶只記一次（依 key 去重），有分類與人物篩選；沒有照片或檔案不見時顯示替代卡片（人物顏色＋日期＋原因）。
- **新女僕**：紬（月見合作後）、千夏（奏合作後）、葵（連鎖咖啡店開幕後）、日和（公園）。店裡最多 6 人。

**除錯（F3）**：每位 NPC 的狀態、目前工作與步驟、候選工作與分數／原因、放棄原因、待辦工作、今天的到店計畫與原因、關係變化原因、記憶觸發來源、即時健康檢查。

## 程式結構

```
godot/scripts/core/   純邏輯（不依賴畫面，可無頭測試）
  data.gd        全部內容資料
  state.gd       遊戲狀態、存讀檔（二進位精確保存）
  layout.gd      地圖、尋路、家具擺放與動線
  business.gd    營業／打烊後的即時模擬
  world.gd       商店街、採購、家具、活動、天氣與街道事件
  settlement.gd  結算、記憶分層、關係、口碑、隔天
  social.gd      女僕心事
  life.gd        個人生活：喜好、休假、找店長、約定、個人故事、雙人事件、客人生活
  life_data.gd   上面這些的內容資料（全部原創）
  moments.gd     每日瞬間
  events.gd      夜間劇情
godot/scripts/view/   3D 畫面與介面
godot/tests/          自動化測試與自動遊玩
```
